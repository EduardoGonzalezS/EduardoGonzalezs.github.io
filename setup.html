⚙️ Configuración de base de datos

Inicio / Configuración
⏱️ ~20 min
☁️
¿Para qué sirve esto?
Esta guía conecta el sitio con Google Sheets como base de datos real. Una vez configurado, todo lo que captures en el sitio (recetas, compras, proveedores) se guardará en la nube y estará disponible desde cualquier dispositivo.
Tu progreso
0 de 5 pasos completados
1

Crear el Google Sheets

Crea la hoja de cálculo con 6 pestañas y sus columnas

  1. Ve a sheets.google.com e inicia sesión con tu cuenta de Google.
  2. Crea una hoja nueva: clic en + En blanco.
  3. Cambia el nombre al archivo (clic en "Hoja de cálculo sin título"): escribe RB Repostería.
  4. Agrega las 6 pestañas de abajo y pega los headers exactamente como aparecen.
Cómo agregar pestañas: clic derecho en la pestaña inferior → "Insertar hoja" o clic en el botón + al final de las pestañas. Los nombres deben ser exactamente como aparecen (sin mayúsculas, sin acentos).

Guarda ese ID — lo necesitarás en el siguiente paso.

2

Crear el Apps Script

Copia el código de la API en el editor de Google

  1. Abre script.google.com → clic en "Nuevo proyecto".
  2. Borra todo el código que aparece por defecto (selecciona todo → Supr).
  3. Abre el archivo apps-script-code.js que está en la carpeta del sitio, selecciona todo su contenido (Ctrl+A) y pégalo en el editor.
  4. En la línea 1 del código, reemplaza TU_SPREADSHEET_ID_AQUI con el ID que copiaste en el paso anterior:
Antes (línea 1 del script)
const SHEET_ID = 'TU_SPREADSHEET_ID_AQUI';
Después (con tu ID real)
const SHEET_ID = '1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms'; // ← tu ID aquí
  1. Guarda el proyecto: Ctrl+S (o Archivo → Guardar). Puedes nombrarlo "RB API".
3

Desplegar como Web App

Publica el script como API accesible desde el sitio

  1. En el editor de Apps Script, clic en el botón azul "Implementar" (arriba a la derecha).
  2. Selecciona "Nueva implementación".
  3. Clic en el ícono de engranaje ⚙️ junto a "Seleccionar tipo" → elige "Aplicación web".
  4. Configura los campos:
    • Descripción: RB Repostería API (o cualquier texto)
    • Ejecutar como: Yo (tu-correo@gmail.com)
    • Quién tiene acceso: Cualquier persona ← importante
  5. Clic en "Implementar".
  6. Google pedirá que autorices permisos. Sigue los pasos:
    • Clic en "Autorizar acceso"
    • Selecciona tu cuenta de Google
    • Es posible que aparezca "Google no verificó esta app" → clic en "Configuración avanzada" → "Ir a RB API (no seguro)"
    • Clic en "Permitir"
  7. Al terminar, aparecerá una pantalla con la URL de la aplicación web. Cópiala. Termina en /exec:
https://script.google.com/macros/s/AKfycby...TuIdLargo/exec
⚠️ Guarda esa URL ahora. Si cierras la ventana, puedes recuperarla desde Implementar → Administrar implementaciones → copiar la URL del tipo "Aplicación web".
¿Por qué "Cualquier persona"? El sitio es HTML estático, no tiene servidor propio para autenticar. La URL del script actúa como clave de acceso. Mientras no compartas esa URL públicamente, los datos están seguros.
4

Conectar el sitio con la API

Pega la URL en js/api.js para que el sitio se conecte

  1. Abre el archivo js/api.js en la carpeta del sitio (con cualquier editor de texto).
  2. Busca la línea 3 que dice TU_URL_APPS_SCRIPT_AQUI.
  3. Reemplaza esa cadena con la URL /exec que copiaste en el paso anterior:
js/api.js — línea 3 (antes)
const API_URL = 'TU_URL_APPS_SCRIPT_AQUI';
js/api.js — línea 3 (después)
const API_URL = 'https://script.google.com/macros/s/AKfycby.../exec';
  1. Guarda el archivo.
5

Verificar que todo funciona

Prueba la conexión y registra tu primer dato

Prueba 1 — Verificar la API directamente:

Abre en el navegador la URL de tu App Script con ?entity=recetas al final:

https://script.google.com/macros/s/TU_ID/exec?entity=recetas

Debes ver [] (arreglo vacío en JSON). Si ves eso, la API funciona correctamente.

Si ves una página de error HTML de Google (no JSON), el problema más común es que el acceso no está configurado como "Cualquier persona". Regresa al paso 3 y crea una nueva implementación con esa configuración.

Prueba 2 — Registrar el primer ingrediente:

  1. Ve a Registrar compra.
  2. Llena la fecha, lugar y al menos un producto con precio.
  3. Clic en "Guardar compra".
  4. Abre tu Google Sheets → pestaña compras. Debe aparecer una fila nueva.
  5. Revisa también la pestaña compras_detalle e ingredientes.

Prueba 3 — Verificar lectura en el sitio:

  1. Ve a Catálogo de ingredientes.
  2. Debe aparecer el ingrediente que acabas de registrar en la tabla.
  3. Si ves "Sin ingredientes registrados", espera 5 segundos y recarga — la primera carga puede tardar un poco.
Nota sobre velocidad: La primera petición al Apps Script puede tardar 3-5 segundos porque Google "despierta" el servidor. Las peticiones siguientes son más rápidas.

Solución de problemas comunes

Si algo no funciona, revisa estos casos

❌ La página muestra "Error de conexión"

  • Verifica que la URL en js/api.js esté completa y termine en /exec (no /dev).
  • Asegúrate de que la implementación sea tipo "Aplicación web" con acceso "Cualquier persona".
  • Abre la URL directamente en el navegador — si muestra HTML de error de Google, el acceso no está bien configurado.

❌ Guarda pero los datos no aparecen en Sheets

  • Verifica que el SHEET_ID en el Apps Script sea correcto (sin espacios ni caracteres extra).
  • Confirma que los nombres de las pestañas en Sheets son exactamente recetas, ingredientes, etc. (todo minúscula, sin acentos).
  • En el editor de Apps Script, busca el menú Ejecuciones para ver si hay errores con detalles.

❌ Modifiqué el código pero los cambios no funcionan

  • Cada cambio en el Apps Script requiere una nueva implementación. Ve a Implementar → Nueva implementación (no "Administrar implementaciones existentes").
  • Actualiza la URL en js/api.js con la nueva URL si cambió.

❌ "Google no verificó esta app" al autorizar

  • Esto es normal para scripts personales. Clic en "Configuración avanzada" → "Ir a [nombre del script] (no seguro)" → "Permitir".
  • Solo aparece la primera vez o si cambias los permisos.

❌ Los costos de las recetas salen en $0.00

  • El costo se calcula con el campo precio_por_base de cada ingrediente. Este campo se llena automáticamente cuando registras una compra de ese ingrediente.
  • Registra al menos una compra de cada ingrediente antes de crear recetas.
